# Restaurant Order System in Python

This is a simple Python program that simulates a restaurant ordering system. 
Users can order items from a menu, see their total bill, and view the total quantity of items ordered.

## Features
- Display the menu with prices
- Take multiple orders from the user
- Calculate and display the running total after each order
- Show the list of all ordered items and the total quantity when the user exits

## Menu Items
- Burger - $5
- Pizza - $7
- Tacos - $10
- Fries - $3
- Drinks - $3
